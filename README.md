# Mold Jacket Generator — Blender Add-on (Опалубка для силиконовых форм)

Blender-аддон для генерации разборной жёсткой опалубки (жакета/формы-каркаса)
вокруг мастер-модели для последующей заливки силиконовой формы.

Аддон повторяет очертание мастер-модели с равномерным отступом (зазором) —
именно в этот зазор заливается силикон, — добавляет стенку опалубки заданной
толщины, ставит модель на ступенчатую подставку (чтобы силикон не затекал
под модель) со штифтами-фиксаторами, разбивает опалубку на 2 (или больше)
разборные части с крылышками для струбцин/резинок и замками
"мама/папа" (шарик + гнездо) для точного повторного совмещения половинок.

Файл аддона: [`mold_jacket_addon.py`](./mold_jacket_addon.py) — один файл,
устанавливается стандартным способом через Blender Preferences.

## Установка

1. Скачайте файл `mold_jacket_addon.py`.
2. В Blender: `Edit > Preferences > Add-ons > Install...`, выберите файл.
3. Включите галочку у аддона "Mold Jacket Generator".
4. Панель появится в 3D Viewport, в боковой панели (клавиша `N`), вкладка
   **Mold Jacket**.

Совместимость: Blender 3.3+ (протестировано на Blender 4.0).

## Единицы измерения

Все размеры — это стандартные Blender `DISTANCE`-поля: они всегда
отображаются в единицах, заданных в `Scene Properties > Units`, и в поле
можно вводить значения прямо с суффиксом, например `4mm`, `0.3cm` — Blender
сам переведёт. Для удобства рекомендуется выставить
`Unit System = Metric`, `Unit Scale = 0.001`, `Length = Millimeters`,
тогда 1 единица Blender = 1 мм.

**Важно:** если у вашей сцены уже настроен другой `Unit Scale` (например,
многие модели делают в конвенции "1 единица Blender = 1 мм" при
`Unit Scale = 0.001`), просто печатайте значения в полях аддона с явным
суффиксом (`4mm`) — Blender сам корректно пересчитает число под вашу сцену.
Не полагайтесь на значения по умолчанию "как есть", если не уверены, что
`Unit Scale` сцены не менялся — при печати с суффиксом это не имеет
значения, аддон был проверен на сценах с обеими конвенциями.

## Мастер-модель: требования

* Один меш-объект, **замкнутый** (watertight, без дыр в геометрии) —
  например экспортированный/скульптированный "зайка" целиком.
* Реальный масштаб (размер в мм/см должен соответствовать реальному изделию),
  так как зазор и толщина стенки задаются в реальных единицах.

## Пошаговый порядок работы

### 1. Prepare Master — обрезка дна ("без дна")

Мастер-модель дублируется, и всё что ниже заданной высоты `Cut Height`
удаляется **без крышки** (дно остаётся открытым) — именно так модель будет
стоять на подставке. Кнопка рядом с полем ставит `Cut Height` на нижнюю
точку модели как отправную точку — подвиньте повыше, если у скульптуры есть
цельное основание, которое нужно убрать.

### 2. Base Plate — ступенчатая подставка

Строится круглая подставка под пятном модели:

* внешний плоский диск (`Base Plate Margin`, `Base Plate Thickness`),
* нижняя широкая ступень (`Outer Step Height/Width`) — именно на неё
  садится нижний край опалубки, и она же образует бортик, не дающий
  силикону затекать наружу,
* верхняя узкая ступень (`Inner Step Height/Width`), на которую опирается
  сама модель,
* штифты-фиксаторы (`Alignment Pin Count/Diameter/Height`) по внешней
  ступени — под них в опалубке автоматически прорезаются ответные отверстия.

### 3. Mold Jacket — опалубка

Основные параметры:

* **Silicone Gap** — зазор между поверхностью модели и внутренней
  стороной опалубки (тот самый промежуток, куда льётся силикон), по
  умолчанию 4 мм.
* **Jacket Wall Thickness** — толщина стенки самой опалубки.
* **Detail (Voxel Size)** — точность построения смещённых поверхностей
  (меньше = точнее и медленнее).
* **Top Collar Margin** — на сколько опалубка выступает выше самой высокой
  точки модели (верх всегда открыт — через него заливают силикон).
* **Number of Parts** — на сколько частей разбить опалубку (2 — классический
  разъёмный жакет, как на референсных фото; можно больше).
* **Split Angle Offset** — поворот линии разъёма вокруг модели.
* **Wings** — крылышки по бокам каждого шва с отверстиями под
  струбцины/резинки/болты (`Wing Width/Height/Thickness`,
  `Wing Clamp Hole Diameter`, `0` — без отверстия).
* **Mama/Papa Locks** — шарики-замки вдоль шва: на одной половинке —
  выступ ("папа"), на другой, в том же месте — гнездо с зазором на
  посадку ("мама"), для однозначной и точной сборки половинок.

Нажмите **Generate Jacket** — либо сразу **Generate All**, чтобы выполнить
шаги 1–3 подряд текущими настройками.

## Результат

Все созданные объекты попадают в отдельную коллекцию
`MoldJacket - <ИмяМодели>`:

* `<Имя>_MoldSource` — подготовленная (обрезанная снизу) копия модели;
* `<Имя>_BasePlate` — подставка;
* `<Имя>_JacketPartN` — части опалубки (готовы к экспорту в STL для печати).

Оригинальная мастер-модель никогда не изменяется — аддон всегда работает
на дублированных копиях.

## Как это устроено внутри (коротко)

Зазор и стенка строятся через `Solidify` (смещение поверхности наружу) +
`Remesh (Voxel)` для очистки самопересечений в вогнутых местах (например,
между ушами) — это надёжно работает даже на сложной скульптурной геометрии.
Разбиение на части и крылышки/замки — через булевы операции (`Boolean`,
solver `EXACT`) с процедурно построенными «нож»-мешами (клин, коробка,
цилиндр, сфера). После каждого этапа цепочки булевых операций выполняется
дополнительный `Remesh`-проход, иначе даже единичные вырожденные грани
ломают следующую булеву операцию.

Реализация протестирована в headless Blender 4.0.2 на тестовой геометрии
со сложным вогнутым рельефом — генерация проходит без ошибок, все итоговые
части получаются герметичными (manifold, пригодны для 3D-печати).
